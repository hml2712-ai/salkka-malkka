# 살까말까 (salkka-malkka)

중고 시세 · 꿀매물 알림 · 알바 판독 · 아낀 돈 가계부를 한 화면에서 보는 웹앱(PWA)입니다.
설치 없이 링크만 열면 쓰고, 홈 화면에 추가하면 앱처럼 전체화면으로 뜹니다.

- **시세**: 상품명만 넣으면 지금 당근에 올라온 매물을 읽어 **실제 평균가·중앙값·최저가·꿀매물 기준**과 매물 목록을 보여줍니다(무료 미니 서버 연결 시). 서버를 붙이기 전에는 상품 사진·목록 캡처를 올려 사진 속 글자를 읽어(브라우저 내 한국어 OCR) 가격을 뽑거나, 당근에서 본 가격 몇 개를 직접 넣어 계산하고, 미리 넣어둔 품목 시세를 참고용 샘플로 볼 수 있습니다.
- **꿀매물**: 물건 이름과 알림 기준(평균가 −20/30/40% 또는 직접 희망가)을 등록해 두면 어떤 매물이 걸리는지 보여줍니다.
- **알바**: 공고 **링크(URL)** 를 붙여넣으면 공고 내용을 읽어와 바로 위험도를 판독합니다(당근알바·알바몬·알바천국). `[당근알바] 굽네치킨 알바 https://jobs.daangn.com/...` 처럼 제목·설명이 섞인 공유 문구를 통째로 붙여넣어도 링크만 골라 읽습니다. 링크가 없으면 공고 글을 붙여넣거나 공고 캡처를 올리면 사진 속 글자를 읽어 자동으로 채우고, 위험 신호를 항목별로 짚어 위험도를 계산합니다. (2026년 최저시급 10,320원 기준)
  - 공식 플랫폼 공고는 개인정보 보호를 위해 본문에 전화번호 대신 [지원하기]·[전화하기] 버튼만 두므로, **전화번호 미기재를 감점하지 않습니다.** 상호·근무지·급여(최저시급 이상)가 확인되고 수상한 신호(계정·명의 요구, 선입금, 메신저 유도, 비현실적 급여, 상호·주소 누락)가 없으면 **안심(80점 이상)** 으로 판정합니다.
- **가계부**: 아낀 금액과 걸러낸 위험 알바를 기록하고 이번 달 목표(300,000원) 대비 진행률을 봅니다.

## 쓰는 법

1. 휴대폰 브라우저에서 아래 주소를 엽니다.
   - https://hml2712-ai.github.io/salkka-malkka/
2. 홈 화면에 추가합니다.
   - **iPhone(사파리)**: 공유 버튼 → `홈 화면에 추가`
   - **Android(크롬)**: 오른쪽 위 ⋮ → `앱 설치` 또는 `홈 화면에 추가`
3. 홈 화면 아이콘으로 열면 주소창 없이 앱처럼 뜹니다.

## 저장에 대해

- 알림 목록과 가계부 기록은 **그 기기의 브라우저(localStorage)에만** 저장됩니다. 서버로 보내지 않습니다.
- 브라우저 데이터를 지우면 기록도 함께 사라지니, 큰 금액은 따로 메모해 두세요.
- **사진 글자 인식(OCR)은 기기 안에서만** 처리하고 사진을 서버로 보내지 않습니다. 처음 한 번만 글자 인식 도구·데이터를 내려받으며(인터넷 필요), 그다음부터는 캐시로 씁니다. 불러오지 못하면 직접 입력으로 넘어갑니다.
- 시세 카드에 미리 넣어둔 품목 값은 **참고용 샘플 예시**입니다. 실제 매물 가격은 결과 카드의 🥕 버튼으로 당근 검색에서 확인하고, ‘실제 매물 가격으로 계산’에 당근에서 본 가격을 넣으면 실물 기준으로 다시 계산됩니다.

## 실시간 시세·알바 링크 서버(Worker) 붙이는 법

상품명만 넣어 **실제 당근 매물 평균가**를 보고, 알바 공고 **링크만 넣어** 바로 판독하려면 무료 미니 서버가 하나 필요합니다. `worker.js` 한 파일이 그 서버입니다(외부 라이브러리 없음).

1. https://dash.cloudflare.com 에서 무료로 가입합니다.
2. **Workers & Pages → Create → Worker** 를 누르고 이름을 정합니다(예: `salkka-malkka`).
3. **Edit code** 를 눌러 기본 코드를 지우고 `worker.js` 내용을 그대로 붙여넣은 뒤 **Deploy** 를 누릅니다.
4. 생긴 주소(`https://salkka-malkka.내계정.workers.dev`)를 복사합니다.
5. 앱 **시세 탭 → 실시간 시세 서버 연결** 에 주소를 붙여넣고 **[연결하기] → [연결 확인]** 을 누릅니다.

- 주소를 코드에 고정하려면 `index.html` 의 `DEFAULT_WORKER_URL` 한 줄만 바꾸면 됩니다.
- 무료 요금제 한도(하루 10만 요청) 안에서 쓰는 개인용 규모라면 비용은 0원입니다.
- 서버에는 **검색어와 공고 주소만** 지나갑니다. 사진, 가계부, 알림 목록은 여전히 폰 안에만 저장됩니다.
- 당근 웹 검색은 동네를 좁힐 수 없어 **전국 매물 기준**입니다. 또 당근이 자동 접속을 막으면 시세가 안 나올 수 있어, 그때는 앱이 자동으로 기존 사진·직접 입력 방식으로 안내합니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 전체 (한 파일에 화면·스타일·동작 포함) |
| `worker.js` | 실시간 시세·알바 공고 읽기용 Cloudflare Worker (대시보드에 붙여넣어 배포) |
| `manifest.json` | 홈 화면 앱 정보(이름, 색, 아이콘) |
| `sw.js` | 오프라인에서도 열리게 하는 서비스 워커 |
| `icon-192.png` / `icon-512.png` | 앱 아이콘 |
| `icon-180.png` | iOS 홈 화면 아이콘 |
| `icon-maskable-512.png` | 안드로이드 마스커블 아이콘 |
